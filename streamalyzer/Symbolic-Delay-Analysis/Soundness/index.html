The key functoriality/naturality facts used throughout the soundness proof:

  • abstractPreservesStep: applying a packet map f : α → β commutes with a single device step. Formally, abstracting the state and input before the step gives the same output-and-state pair as running the device on the abstracted inputs. This follows directly from GoodSystem.device_natural.

  • runDeviceSteps_natural: the naturality extends to k-step runs: for any f : α → β and compatible branching function hb, (mapKOTuple f out, Functor.map f s') = runDeviceSteps (sys.device hb) (mapKStreams f R) (Functor.map f s) k.

  • stateBeforeTime_natural: the state before time t commutes with packet maps, Functor.map f (stateBeforeTime sys (hb ∘ f) R t) = stateBeforeTime sys hb (mapKStreams f R) t.

These are the foundational lemmas that let the proof move between packet worlds.
